# إقامة البيانات (الحالة والخيارات)
- المشروع الحالي على Supabase السحابي في **سنغافورة (ap-southeast-1)**؛ لا توجد منطقة سعودية في Supabase السحابي حسب القائمة المنشورة. الأقرب: مومباي أو أوروبا.
- بدائل داخل المملكة: **تشغيل Supabase مفتوح المصدر ذاتيًا** على سحابة سعودية (Google Cloud Dammam، Oracle Jeddah/Riyadh، أو مزوّد محلي). الشيفرة والترحيلات والدالة تعمل كما هي؛ يتغير فقط عنوان المشروع والمفاتيح في `web/config.js`. العبء: النسخ والترقيات والأمان والتوافرية على فريقكم.
- الواجهة الثابتة (Cloudflare) لا تحمل بيانات أعمال؛ البيانات تذهب من المتصفح إلى قاعدة البيانات مباشرة.
- لا تُدخل بيانات مرضى. وجود بريد/اسم الموظفين يجعلها بيانات شخصية: يلزم رأي قانوني/امتثال (PDPL) قبل الإنتاج. هذا الملف ليس رأيًا قانونيًا.
